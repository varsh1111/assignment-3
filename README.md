#  Study Space

School can sometimes feel overwhelming and difficult to manage, especially when you have a lot of schoolwork piling up. That's why I created Study Space, an application that helps students keep track of their studies. it's a study planner where students can organize their studies, keep track of assignments and exams and monitor their own progress.

## Implementation
I built Study Space using vibe coding with AI development tools such as Lovable and ChatGPT. I first described what i wanted to create and the features i wanted the study planner to have using Lovable. Lovable created the first prototype and I uploaded my project to Github and deployed the application using Vercel. Then I tested Study Space out to check if it worked. I also used ChatGPT to make some improvements and added more features. I wanted the application to be user-friendly so i tried to make it simple and easy to use. Throughout this project I learned how to make an application with the help of AI. This gave me an opportunity to experiment with AI and inspired me to create better applications like this in the future.

## Features
- Dashboard with the current date, total subjects, assignment completion, deadlines, weekly goals, upcoming exams and study streaks.
- Sidebar with subject pages.
- Assignment due dates and low/medium/high priority labels.
- Exam tracker with revision topics and confidence status.
- Study session logging, weekly goals, study days streaks.
- Progress reports and achievement badges.
- Data saved in the browser using local storage.
